# Contributing to JANA-GATISHAKTI DPI

We welcome contributions from developers, civic tech advocates, and data scientists across BRICS nations!

## Development Workflow

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/vernacular-dialect-support`
3. Commit your changes: `git commit -m 'feat: Add Bhojpuri keyword support for flood damage'`
4. Run tests: `python tests/test_backend.py`
5. Push to your branch and submit a Pull Request.

## Code Standards
* Follow PEP 8 guidelines for Python code.
* Ensure all citizen voice processing components strictly enforce non-PII sanitization (DPGA Indicator 6).
* All new endpoints must be documented in OpenAPI/Swagger specs.
