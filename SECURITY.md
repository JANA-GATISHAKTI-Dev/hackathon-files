# Security Policy

## Reporting Security Issues

As a Digital Public Good handling citizen feedback and sovereign infrastructure data, security and citizen privacy are paramount.

If you discover a security vulnerability or PII leakage bug:
1. Please report it privately by emailing `security@janagatishakti.gov.in`.
2. Do not disclose vulnerabilities in public GitHub issues.
3. The security team will triage and respond within 48 hours.

## PII Sanitization Guarantee
Jana-GatiShakti operates under a **Zero-Knowledge PII Ingestion Policy**. No raw Aadhaar numbers, phone numbers, or residential addresses are ever persisted to the analytics database.
